# Justin Jackson Portfolio

A portfolio of my background, creative projects, and progress through the ed2go Web Design Professional program.

## Built with

- HTML, CSS, and JavaScript
- Bootstrap 5.2.3, included locally in `bootstrap-5.2.3-dist/`

## View the site

Open `index.html` in a browser. No build step or package installation is required.

The portfolio includes a resume, project showcase, color-theory and typography coursework, quizzes, and a contact page. The site wide navigation also includes theme and text-size controls.
